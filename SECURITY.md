# Security Policy

## Supported versions

Security fixes apply to the latest release in the `1.x` series. Earlier minor and patch releases should be upgraded to the latest available `1.x` release.

The supported runtime is PHP 8.3 or later with Laravel 12 and 13.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use [GitHub private vulnerability reporting](https://github.com/EvanSchleret/laravel-uuidable/security/advisories/new) when it is available for this repository. If the reporting form is unavailable, email [evan@schleret.ch](mailto:evan@schleret.ch).

Include enough detail to help reproduce and assess the issue. Do not include credentials, access tokens, or unrelated personal data. The maintainer will coordinate a response and disclosure with the reporter.
