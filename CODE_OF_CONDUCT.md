# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies to project spaces, including issues, pull requests, and other community interactions.

Project participants are expected to help maintain a respectful, inclusive, and harassment-free environment. The full Covenant describes expected conduct, unacceptable behavior, and the enforcement guidelines.

## Reporting

Report abusive, harassing, or otherwise unacceptable behavior privately to [evan@schleret.ch](mailto:evan@schleret.ch). Reports will be reviewed confidentially and handled fairly. Project maintainers may remove, edit, or reject contributions that do not follow this Code of Conduct.
